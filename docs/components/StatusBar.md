# Спецификация компонента: Глобальная строка состояния (StatusBar)

## 1. Контракты (Интерфейсы и Архитектура)
Используется паттерн **Compound Components**, чтобы строка состояния выступала в роли гибкого "глупого" контейнера, а дочерние элементы управляли своими данными самостоятельно (например, счетчик ошибок сам подпишется на свой Store).

```tsx
interface StatusBarItemProps {
  id: string;
  icon?: React.ReactNode; 
  text?: string | number;
  tooltip?: string;
  onClick?: () => void;
  status?: "default" | "error" | "warning" | "success" | "active";
}

// Архитектура использования:
<StatusBar>
  <StatusBar.Left>
     <StatusBar.Item id="output" icon={<Terminal />} text="Output" onClick={...} />
  </StatusBar.Left>
  <StatusBar.Right>
     <StatusBar.Item id="encoding" text="UTF-8" tooltip="File Encoding" />
  </StatusBar.Right>
</StatusBar>
```

## 2. Логика и Стейт
- **Глобальная зависимость**: Сам контейнер `StatusBar` независим и может переиспользоваться. Бизнес-логику (чтение `useLogStore`, вызовы `uiStore`) реализуют конкретные элементы, которые мы передадим в него.
- **Интерактивность**:
  - Элементы, принимающие `onClick`, получают `cursor-pointer`.
  - Элементы только для чтения получают `cursor-default`.
- **Всплывающие подсказки**: Встроенная поддержка Tooltips (Radix UI) при наведении на любой `StatusBar.Item` (задержка 500мс) для пояснения неочевидных иконок.

## 3. UI и Верстка (High-Density IDE Mode)
- **Размеры**: Ультра-компактная высота контейнера `h-[22px]`.
- **Шрифты**: Системный шрифт без засечек, размер `text-[10.5px]`. 
- **Цветовая палитра**:
  - Фон статусной строки: `bg-primary` (акцентный цвет проекта для визуального отбивания низа IDE), текст `text-primary-foreground`.
  - Hover-эффект элементов: затемнение/осветление фона `hover:bg-black/20`.
- **Отступы**: Внутри элемента `px-1.5`, иконки `w-3 h-3 mr-1.5`. Выравнивание `flex justify-between`.

## 4. Матрица состояний и Edge Cases
| Состояние | Поведение |
| :--- | :--- |
| **Сужение окна (Overflow)** | Центральная зона имеет `overflow-hidden`. Текст обрезается с помощью `truncate` (появляется троеточие). |
| **Длинный текст** | Если текст обрезан, его полная версия всегда доступна в Tooltip при наведении. |
| **Критические элементы** | Кнопки и иконки (со счетчиком ошибок) имеют `shrink-0` и никогда не сплющиваются. |
| **Пустой контент** | Если нет текста, `StatusBar.Item` рендерит только иконку центрированно. |
